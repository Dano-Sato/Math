We study a bounded-integer spherically symmetric tree with branching sequence \((b_n)\), branching number \(b=\operatorname{br}(T)\), and radial Jacobi off-diagonals \(\sqrt{b_n}\).

For a finite block \(w=(c_1,\dots,c_m)\), define
\[
K_b(w)=
\begin{pmatrix}
\sqrt b & \sqrt{c_1} & &\\
\sqrt{c_1}&0&\ddots&\\
&\ddots&0&\sqrt{c_m}\\
&&\sqrt{c_m}&\sqrt b
\end{pmatrix}.
\]
Call \(w\) screened if
\[
\lambda_{\max}(K_b(w))\le 2\sqrt b.
\]

### Finite Screening Conjecture (FSC)
\[
\boxed{
\rho_{\rm ess}(T)=2\sqrt b
\iff
(b_n)_{n\gg1}\in\mathcal C_b^\omega
}
\]
where \(\mathcal C_b\) is the set of screened finite blocks.

Normalize \(\beta_n=b_n/b\). At threshold \(2\sqrt b\),
\[
x_{n+1}=2-\frac{\beta_n}{x_n},
\qquad
\beta_n=x_n(2-x_{n+1}).
\]
A block started at \(x_0=1\) is screened iff
\[
x_j>0\ (j<m),\qquad x_m\ge1.
\]

Useful identity:
\[
\prod_{j=0}^{m-1}\beta_j
=
(2-x_m)\prod_{j=1}^{m-1}\bigl[1-(1-x_j)^2\bigr].
\]

Known:
- screened tail factorization \(\Rightarrow \rho_{\rm ess}=2\sqrt b\);
- nonconstant periodic branching gives \(\rho_{\rm ess}>2\sqrt{\operatorname{br}(T)}\);
- minimal spectral edge does **not** force the distinguished Riccati orbit from \(x_0=1\) to return to \(1\).

Indeed, for \(b=4\), with
\[
q=(1-x)^{-1},\qquad
F_c(q)=\frac{4(q-1)}{(c-4)q+4},
\]
one can construct a bounded-integer infinite word with
\[
0<x_n<1\ \forall n,\qquad \limsup x_n=1,\qquad \operatorname{br}(T)=4,
\]
and still \(\rho_{\rm ess}(T)=4\).

This is **not** an FSC counterexample because the same word admits another parsing into screened blocks such as
\[
(5,3),\qquad(7,1),\qquad(4).
\]

Therefore the true hard direction is:
\[
\boxed{
\rho_{\rm ess}(T)=2\sqrt b
\Longrightarrow
\text{existence of some screened tail factorization}.
}
\]

Promising proof route:
show that a tail with no screened factorization yields a recurrent irreducible bad pattern/right limit whose Jacobi spectral radius is \(>2\sqrt b\).

Counterexample route:
for \(b=6\), let
\[
y=\frac1{1-x},\qquad
T_c(y)=\frac{6(y-1)}{(c-6)y+6}.
\]
Background digit \(6\) acts by \(y\mapsto y-1\).

Search for admissible words \(W\) with
\[
5\xrightarrow{W}Y\in\mathbb Z
\]
and large
\[
\frac{Y}{|W|}.
\]
Then
\[
5\xrightarrow{W}Y\xrightarrow{6^{Y-5}}5
\]
is an exact Riccati cycle.

Define the Reachability Growth problem:
\[
\boxed{
\sup\left\{
\frac{Y}{|W|}:
5\xrightarrow{W}Y\in\mathbb Z,\ W\text{ admissible}
\right\}
\stackrel{?}{=}\infty.
}
\]

A YES gives strong candidates for critical aperiodic examples, but to refute FSC one must additionally prove that the resulting infinite word has **no alternative screened factorization**.

Current status: FSC and the weaker asymptotic version remain open. The core issue is now a language/factorization problem, not finite return of one Riccati orbit.
